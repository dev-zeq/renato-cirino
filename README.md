# Renato Cirino — Portfólio
Site estático mobile-first em HTML, CSS e JavaScript, sem build ou dependências.

## Desenvolvimento
Execute `python3 -m http.server 8080` na raiz e abra http://localhost:8080.

## Hospedagem
GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
Domínio próprio será definido posteriormente; não adicionar CNAME antes disso.
